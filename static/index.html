🔌 API Dokumentation 
GET    /api/health                 - Server Status
GET    /api/temperatures           - Liste aller Messungen (?limit=50&offset=0&sensor_id=x)
GET    /api/temperatures/latest    - Neueste Messung
GET    /api/temperatures/:id       - Einzelne Messung
POST   /api/temperatures           - Neue Messung anlegen
  Body: { "temperature": 21.5, "sensor_id": "sensor-1", "location": "Wohnzimmer", "timestamp": "2024-01-01T12:00:00Z" } (letzte 3 Felder optional)
DELETE /api/temperatures/:id       - Messung löschen
DELETE /api/temperatures           - Alle Messungen löschen
GET    /api/stats                  - Statistiken (count, avg, min, max)

Beispiel mit curl:
curl -X POST http://localhost:3000/api/temperatures -H "Content-Type: application/json" -d '{"temperature":23.4,"sensor_id":"s1","location":"Büro"}'
curl http://localhost:3000/api/temperatures | jq
